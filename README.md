## MATTER — 元素与分子实验室

一个纯前端的交互式化学教学站点，**无需联网、无任何外部依赖**。

### 功能

| 模块 | 说明 |
| --- | --- |
| **01 元素图谱** | 完整 118 元素周期表，单击查看 2D 原子结构（电子层 / 排布 / 相对原子质量），支持按名称、符号、序号搜索 |
| **02 分子构建台** | 单击元素查看结构 → 手动设定数量 → 点「加入分子构建器」；可拼接多元素组成式，再「加入反应物」 |
| **03 反应演示** | 由用户主动点击「合成反应」触发，自动配平并播放 5 分镜演示视频 |
| **04 试剂知识库** | MnO₂、V₂O₅、Pt、Ni 等催化 / 氧化剂的参考信息 |

### 反应演示视频

- **5 段分镜**：装载 → 就位 → 活化 → 重排 → 产物，可点击分镜直接跳转
- **旁白字幕**：按反应数据动态生成，含真实配平系数与催化条件，可开关
- **播放控制**：播放 / 暂停 / 重播 / 0.5×–2× 变速 / 时间轴拖拽 / 全屏
- **视频 HUD**：REC 指示灯 + 运行时间码 + 章节标题卡

### 交互约定

- 单击周期表元素**只会查看结构**，不会自动跳转页面
- 是否加入分子构建器，由用户点击「＋ 加入分子构建器」确认（可先设定数量）
- 反应物数量不设上限

### 设计原则

> 只演示已收录的 20 条真实反应路径，**不做产物预测**。组合不匹配时明确显示「未找到已验证的反应」，不会编造方程式。

所有方程式使用高斯消元 + 分数运算做原子守恒配平；动画中的原子数量与配平结果严格一致。

### 运行

直接用浏览器打开 `index.html` 即可（支持 `file://` 本地打开）。

```
Element-Lab/
├── index.html
└── assets/
    ├── app.css     # 样式
    ├── data.js     # 118 元素、物种、20 条反应路径、试剂数据
    └── app.js      # 配平算法、Canvas 渲染、播放器、交互
```

### 说明

内容仅供教育参考。真实反应条件依赖温度、压力、浓度及动力学等因素；本项目不提供实验操作步骤或安全保证。
